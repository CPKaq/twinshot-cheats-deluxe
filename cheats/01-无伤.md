## 1. 效果定义

- 玩家看到的最终效果:受到攻击时攻击不生效
- 生效范围:所有攻击（不包括被箭射中）

## 3. 实现选型(Phase 3)

- [ ] 写字段(锁数值)-> 需要每帧/事件触发?
- [x] patch 方法(直接返回或改参数)-> patch 时机:方法需先被 JIT 调用过一次
- [ ] 调用游戏自己的方法(如清除状态)

**选型:patch `Player.Hit(Vector2)` 的 JIT 入口,无条件返回 false。**

理由:
- 精准命中"执行扣血之前"的最早返回点,原逻辑一行不执行;
- patch 方法本身,单人/合作全部玩家实例自动共享,无需遍历对象;
- 相比冻结 `flickering` 字段(借 `hitBounce || flickering > 0` 提前返回),没有"永久受击闪烁动画"的副作用。

Phase 3 落地方式(trainer.dll 内):

```cpp
// 1. 经 mono API 定位方法(按名字+签名,不硬编码地址)
mono_class* playerClass = mono_class_from_name(image, "", "Player");
method = 遍历 mono_class_get_methods,匹配 name == "Hit" 且签名 1 个参数(Vector2);
// 2. 编译并拿到 JIT 入口
void* entry = mono_compile_method(method);  // 若已编译则直接返回现地址
// 3. 写入 31 C0 C3 (xor eax,eax; ret),VirtualProtect 改执行权限
// 4. 热键开关:切换时保存/覆盖原始字节(启动作弊=31 C0 C3,关闭=还原)
```

### CE 手动验证流程备忘(Phase 2,路线 A)

1. 进有敌人关卡挨一下,确保方法已 JIT;
2. Mono Dissect → Player → Methods → 选 **Hit(float,float)**(RID 1026,注意与 `Hit()`/`Hit(Arrow)` 区分);
3. 右键方法 Toggle breakpoint → 挨打断下 → 记录入口地址 → 取消断点;
4. Auto Assemble patch:`<入口>: db 31 C0 C3`([DISABLE] 段写入原字节);
5. 挨打验证无伤;还原字节验证伤害恢复。
